# 🧠 Content Strategy Agent

An AI-powered Content Strategy Agent that remembers past content,
analyzes performance, identifies content gaps, and generates
future content recommendations.

## 🚀 Features

- Content memory using SQLite
- Content performance analytics
- Engagement calculation
- Content gap detection
- AI-powered recommendations
- Gemini AI content strategist
- Add and track new content
- AI content strategy questions

## 🛠️ Tech Stack

- Python
- Flask
- SQLite
- Google Gemini API
- HTML
- CSS
- JavaScript

## 🔄 Workflow

Content History
↓
Content Memory
↓
Performance Analysis
↓
Content Gap Detection
↓
Gemini AI
↓
Strategy Recommendations
